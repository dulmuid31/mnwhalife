# mnwhalife
Aplikasi Manhwa Reader berbasis PWA dengan tampilan modern, responsif, dan pengalaman membaca yang nyaman. Mendukung pengelolaan koleksi manhwa, navigasi halaman yang praktis, serta fitur musik latar untuk menghadirkan suasana membaca yang lebih imersif, dramatis, dan menyenangkan. Dirancang ringan dan optimal untuk berbagai perangkat.
